How it decides

Every opportunity is judged by 2–4 analysts who work in blind parallel, then compared, debated and voted by merit weight. Direction comes from each persona's rule evaluated in Python; the language model supplies confidence, stop and evidence. Plain Python then enforces the 5× fee-to-edge test, a 2:1 reward-to-risk floor, Kelly sizing and the 3-position cap — so a model can be wrong without being dangerous.

Losses cost 1.3× more merit than wins earn; a veto that saves money earns +3.50 while one that blocks a winner loses 1.25. Below 70 an agent is retrained automatically.
